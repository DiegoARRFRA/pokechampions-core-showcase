## Language scope

The application has eight languages; the showcase has two. Screenshots preserve each recording’s language and theme. The new batch is primarily Spanish and light-themed; the language demo shows Spanish, English and German in the dark theme. JSON manifests, package identifiers, commands and paths are shared technical artefacts and are not duplicated or translated. Their explanations and image alt text are translated.

Documentation updates do not change the date or scope of historical application validation. Private source remains outside this repository.
