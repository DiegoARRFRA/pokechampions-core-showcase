# Roadmap

[← Overview](../README.en.md) · [Documentation](README.en.md)

## Android and accessibility

Extend physical testing to more devices and complete flows with TalkBack, larger text and different screen configurations.

## Audio and performance

Complete prolonged playback tests and interactions with calls, Bluetooth and focus changes. Investigate frame presentation times, writes and behaviour with large collections.

## Persistence

Expand migration regressions using long-lived data and strengthen cross-feature scenario-transfer tests. Keep data preservation a requirement for updates.

## Mechanics and regulation

Update catalogues and tests for each regulation. Reduce ambiguous or unsupported cases and maintain reproducible generation and source traceability.

## Releases and documentation

Connect release notes to changes and tests. Keep Spanish and English documentation aligned and explain technical decisions that affect application use.
